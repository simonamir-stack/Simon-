# Dentallica Availability

A shared calendar for Jamie, James, Phillip and Simon. It covers a rolling year starting today.

- **Practice nights:** any evening. Each member marks In, Maybe or Can't.
- **Show nights:** Friday and Saturday nights when you'd be in town to play.
- **Colors:** green means everyone's in, amber means nobody's out but there are maybes, red means someone can't, and plain means the night is still waiting on answers. Each day also shows four small tags (Ja, Js, Ph, Si), colored by that member's answer.
- **Quick fill:** mark every Monday (or any weekday) for the year in one step.

`index.html` is the whole app. The published version on claude.ai keeps everyone's answers in a shared store. Opened as a plain file, it saves to that browser only.
